# Team Agent Roadmap

Team Agent is building a self-hosted control plane for teams that share coding agents without sharing account credentials. Roadmap priorities are informed by real team usage, reliability, and contribution cost rather than fixed delivery dates.

## Now: dependable first use

- Reduce installation and pairing to a short, verifiable setup flow.
- Publish deployable Coordinator and Runner release artifacts.
- Improve health checks, error messages, recovery, and backup guidance.
- Document the security and trust boundaries between members, Agent owners, Git repositories, and the Coordinator.
- Make the first shared task easy to demonstrate and reproduce.

## Next: team-ready workflows

- Package Coordinator deployments for common self-hosting environments.
- Add stronger project roles, approval controls, and audit visibility.
- Improve notification and Git hosting workflows.
- Define a stable adapter boundary for additional coding agents.
- Expand end-to-end testing across supported operating systems.

## Later: an open Agent ecosystem

- Support multiple projects and isolated concurrent work.
- Publish an adapter SDK and compatibility tests.
- Build reusable workflow templates and integrations.
- Grow community-maintained deployment guides and Agent adapters.

## How to influence the roadmap

Start a [GitHub Discussion](https://github.com/boxzeemon-beep/team-agent/discussions) with the workflow, affected users, current workaround, and smallest useful outcome. Focused pull requests tied to a confirmed issue are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md).
