# Public adoption kit

This directory contains the working materials for Team Agent's first public adoption cycle. It keeps product claims, outreach, evidence collection, and operating metrics consistent with the current support matrix.

- [`launch-posts.md`](launch-posts.md): channel-specific public launch copy and release-day checks.
- [`design-partner-outreach.md`](design-partner-outreach.md): ideal partner profile, personalized invitation templates, screening, setup, and debrief guides.
- [`case-study-template.md`](case-study-template.md): consent-first structure for turning an observed workflow into a factual public case study.
- [`first-30-days.md`](first-30-days.md): launch sequence, 20-team funnel, weekly scorecard, and operating rules.

Names, contact details, private repository information, raw interviews, and unapproved evidence stay outside the public repository. Replace template fields only with verified information and publication permission.
