# Team Agent launch posts

These drafts are ready to adapt for a public release. They are intentionally factual: replace bracketed fields only with verified links, release details, screenshots, and results. Do not add adoption numbers, performance claims, customer names, or quotes without evidence and permission.

## Canonical product facts

Use these facts consistently across every channel:

- Promise: **The multiplayer lobby for your team's coding agents.**
- Team Agent is open source and self-hosted under the MIT License.
- A browser-only member can assign a task to a Codex Runner contributed by another member.
- The Runner uses the owner's existing local Codex and Git sessions; those credentials are not uploaded to the Coordinator.
- The requester explicitly chooses the Agent.
- The Coordinator keeps shared project conversation, streams progress, and records response, diff, tests, and commit.
- The current release supports one project per Coordinator, Codex first, one configurable shared working branch, and one active code task at a time.
- Coordinator: Docker Compose. Runner: one-time `npx` command from the project page, using the latest GitHub Release artifact.

Canonical links:

- Repository: `https://github.com/boxzeemon-beep/team-agent`
- Release: `https://github.com/boxzeemon-beep/team-agent/releases/tag/v0.2.0`
- Interactive demo: `https://github.com/boxzeemon-beep/team-agent#open-the-demo-lobby`
- Documentation: `https://github.com/boxzeemon-beep/team-agent#deploy-for-your-team`

## GitHub Discussion announcement

**Title**

> Team Agent v0.2.0: the multiplayer lobby for your team's coding agents

**Body**

> We released Team Agent v0.2.0, an MIT-licensed, self-hosted multiplayer lobby for a team's coding agents.
>
> ![Team Agent workflow](https://raw.githubusercontent.com/boxzeemon-beep/team-agent/main/docs/assets/team-agent-demo.gif)
>
> The problem is small but recurring: one teammate has a working Codex setup and Git access; another teammate needs to move the project forward but only has a browser. Team Agent lets the requester choose the owner's shared Agent, submit a task, and follow its progress. The Runner works on the owner's computer with the owner's local Codex and Git sessions. The Coordinator receives project context and task results, but not those credentials.
>
> The current workflow is deliberately narrow:
>
> 1. Start one Coordinator with Docker Compose.
> 2. Invite teammates.
> 3. An owner contributes a Codex Runner with the one-time command generated in the web app.
> 4. A requester chooses that Agent and submits a task.
> 5. The team sees the response, diff, tests, and commit.
>
> Current boundaries: one project per Coordinator, Codex first, one shared working branch, and serialized code tasks. Native Codex approvals stay on the owner's machine.
>
> Repository: https://github.com/boxzeemon-beep/team-agent
> Demo: https://github.com/boxzeemon-beep/team-agent#open-the-demo-lobby
> Release notes: https://github.com/boxzeemon-beep/team-agent/releases/tag/v0.2.0
>
> We are especially interested in feedback from small teams that already use local coding agents: where does pairing feel slow, what should the Coordinator retain, and which Agent adapter should come next?

### r/selfhosted draft

**Title**

> I built a self-hosted coordinator for sharing local Codex Runners with a team

**Body**

> Team Agent is an MIT-licensed Coordinator + Runner tool for a narrow workflow: a teammate with only a browser can assign a coding task to another member's contributed Codex Runner.
>
> The Coordinator runs with Docker Compose and stores project conversation and queue state in SQLite. Each Runner stays on its owner's computer, uses that person's existing Codex and Git sessions, and connects outbound over WebSocket. The requester explicitly chooses the Agent; results include the response, diff, tests, and commit.
>
> Codex and Git credentials stay on the Runner host. The current version supports one project, one shared working branch, Codex, and serialized code tasks. I documented the trust boundaries here: https://github.com/boxzeemon-beep/team-agent/blob/main/docs/security.md
>
> Repository: https://github.com/boxzeemon-beep/team-agent
> Interactive demo: https://github.com/boxzeemon-beep/team-agent#open-the-demo-lobby
>
> I would appreciate feedback on deployment and recovery, especially from people running small services over Tailscale or another private reverse proxy.
