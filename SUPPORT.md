# Support

## Ask a question

Use [GitHub Discussions](https://github.com/boxzeemon-beep/team-agent/discussions) for setup help, deployment questions, and workflow design. Include the Team Agent version, operating system, Node.js version, deployment method, relevant component, and sanitized logs.

## Report a bug

Search [existing issues](https://github.com/boxzeemon-beep/team-agent/issues) and then use the bug report form with reproducible steps. Remove session tokens, Runner tokens, pairing tokens, repository credentials, private source code, and personal data.

## Propose a feature

Use the feature request form for a focused, actionable change. Use Discussions first when the design is exploratory or affects the product direction.

## Security

Follow [SECURITY.md](SECURITY.md) and report vulnerabilities through GitHub private vulnerability reporting.

Community support is best-effort. Response time varies with maintainer availability and issue impact.
